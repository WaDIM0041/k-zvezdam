# Отчёт о локальной сборке

Собран Flask preview-пакет на основе `roman_promo_update.zip` с совместимыми поздними `admin_edit.html` и `style.css`. Корневой `app.py` объединён с читалкой вручную, а не наложен целиком: сохранены интерфейсные функции позднего редактора, добавлены отдельные пути для SQLite и пользовательских изображений, закрытие админки без пароля, CSRF для изменяющих запросов, проверка перенаправлений и медиа-ссылок, безопасная загрузка изображений и HTML-экранирование. Debug выключен. Source whitelist для репозитория исключает БД и pyc, как и секреты, shell-скрипты установки/обновления, service-файлы, редакторские черновики и главы 11–19. Локальный запуск приложения и тесты создают игнорируемые `instance/roman.db` и `__pycache__`; эти scratch-файлы нужно исключить из копирования в репозиторий.

Редакция для preview — пролог seed + главы 1–10 по источникам в `CONTENT-PROVENANCE.json`. Сборка остаётся рабочим допущением, не подтверждённым live-вариантом. Тексты глав не редактировались. Выбраны 11 записей и 28 изображений; каждому телу и изображению соответствует SHA-256 и источник.

Проверено на Windows с Python 3.12 и установленными Flask 3.1.3, Pillow 13.0.0 и Waitress 3.0.2:

- `python -m unittest discover -s tests -v`: 10 тестов прошли. Они проверяют публичные страницы, noindex/canonical, provenance и доступность всех 28 иллюстраций, отключённую без пароля админку, Unicode-пароль и CSRF, небезопасные URL, загрузки изображений, экранирование и полный CRUD-поток черновика.
- Python-файлы прошли синтаксическую проверку через `compile()`.
- Шаблон редактора отрендерен; оба встроенных скрипта проверены Node.js `--check`.
- После браузерного QA руководителем приняты две адресные правки: правило CSS `[hidden] { display: none !important; }` для скрытых элементов и относительные пути CTA/footer промо (`/chapters` и `/`), чтобы локальный preview оставался внутри тестовой читалки. Это фиксирует внесённые изменения, а не заявляет полный браузерный QA с моей стороны.
- В каталоге проекта находятся 7 HTML-шаблонов, 28 иллюстраций глав и 36 статических файлов всего. Контент JSON содержит 11 глав.
- Фактические пустые значения `ROMAN_DATA_DIR`, `ROMAN_DB`, `ROMAN_UPLOAD_DIR` и `SITE_ORIGIN` обрабатываются безопасными defaults; секреты в `.env.example` пусты.

Проверка была локальной, через Flask test client и синтаксический разбор JavaScript. Это не браузерная проверка на разных устройствах и не проверка DNS, TLS, доменного хостинга, production-конфигурации, live-базы или публикации. Политика CSP оставлена в режиме Report-Only из-за существующих inline-стилей и скриптов; она не блокирует исполнение. Gunicorn указан для Unix в `requirements.txt`, но здесь не устанавливался и не проверялся. До будущей публикации требуется подтвердить редакцию, отдельно спланировать миграцию данных и выполнить развёртывание/проверку среды назначения.
