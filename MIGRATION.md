# Миграция и статус комплекта

Этот каталог содержит локальную сборку-превью из переданных материалов и выбранных архивных версий. Действующая база данных сайта не предоставлялась; SQLite создаётся отдельно в `instance/` при первом запуске и наполняется выбранным seed-комплектом.

Локальная сборка и будущий код в частном GitHub-репозитории не означают публикацию или перенос на домен. Доменное развёртывание, DNS/TLS, live-база, пользовательские загрузки и production-настройки остаются отдельным будущим этапом. Сборка не подключается к действующему хостингу. Для превью включён `noindex`; `SITE_ORIGIN` используется только для canonical URL и не подтверждает публикацию.

Контент — предварительная композиция: пролог seed + главы 1–10 из зафиксированных источников, указанных в `CONTENT-PROVENANCE.json`. Это не подтверждённая владельцем live-редакция. Root-черновик главы 11 исключён. Перед будущей публикацией нужно отдельно подтвердить редакцию и сопоставить её с live-контентом.
