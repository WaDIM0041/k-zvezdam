## Где что хранить

| Место | Материалы |
| --- | --- |
| GitHub | Код без секретов, технические инструкции, перечни файлов, SHA-256, отчёты и PR. |
| Существующие разделы Notion | Инструкция, вопросы, учёт приёма и отчёт; ссылки на репозиторий и конкретный PR. Существующие записи сохранять. |
| Приватные вложения Notion или согласованное закрытое хранилище | Базы данных и большие архивы после проверки содержимого, прав получателей и действующего ограничения размера. |

Пароли, заполненные `.env`, приватные ключи и токены не помещать ни в репозиторий, ни на общую страницу, ни в PR/комментарии. Для описания настройки использовать только имена переменных и пустые примеры. `.gitignore` не заменяет проверку перед отправкой.

## Порядок работы

1. Прочитать актуальные вопросы и запросы материалов на существующей странице Notion. Не создавать другую страницу или репозиторий.
2. Сопоставить запросы с описью уже имеющегося комплекта. Комплект из 168 файлов повторно не передавать. Запрашивать только подтверждённо недостающее или изменённое.
3. Проверить новые материалы; зарегистрировать источник, дату снимка, размер, SHA-256, приватное место хранения и результат проверки без секретных значений.
4. Предлагать изменения в ветке `migration/handoff-setup` через PR в `main`. Перед изменением существующего файла прочитать его и сохранить исходное состояние; не перезаписывать чужую работу.
5. В существующие разделы Notion добавить ссылки на репозиторий и фактический PR, запрос на проверку и краткий отчёт. Передать отчёт руководителю Codex через владельца.
6. Слияние выполняет уполномоченный человек после проверки. Этот этап не разрешает развёртывание, изменение сайта, DNS или перезапуск сервисов.

## Доступ и состояние на 23.10.2026

GitHub подключён от `yrkevichtanya-cmd`. Для этого частного репозитория подтверждены чтение и запись (`Write`); `admin=false`, `maintain=false`. Дополнительные права не запрашивались. Проверка не утверждает, что интеграция не имеет доступа к каким-либо другим ресурсам аккаунта.

Notion на момент подготовки не установлен в Codex; указанная страница в браузере требует входа. Аккаунт Notion, права редактирования и содержание её разделов пока не подтверждены. Владелец должен пригласить фактический аккаунт администратора с редактированием только этой страницы, если такого доступа ещё нет. Адрес аккаунта нельзя угадывать.

Пока добавлена ссылка из GitHub на Notion; обратные ссылки ожидают доступа. Автоматической синхронизации нет: связь между сервисами организуется ссылками и ручным обновлением статуса.
